# Contributing

Please open an issue before proposing a substantial workflow or interface
change. Keep source skills and generated bundle skills synchronized with
`npm run sync`, then run `npm run check` and `npm test`.

Do not contribute credentials, private paths, unpublished structures,
trajectories, or machine-specific environment receipts. New scientific
backends need a documented runtime source, deterministic file interface, and
CPU-only contract tests; GPU claims require a reproducible acceptance receipt.
