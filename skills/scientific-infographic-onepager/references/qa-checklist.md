# QA Checklist

## Required Before Delivery
- PNG is nonblank.
- Dimensions match requested width and height.
- No horizontal or vertical overflow.
- No clipped title, module heading, footer, axis label, or caveat text.
- Main claim is readable in the top 35% of the image.
- Chinese body text remains readable at mobile preview size.
- Schematic visuals are marked as schematic.
- Data-backed claims cite source data or an upstream skill output.
- No meaningless decorative labels or fake metadata were added to fill space.
