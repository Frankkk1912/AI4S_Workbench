# Security policy

Report a suspected vulnerability privately through the maintainer's GitHub
profile rather than opening a public issue. Do not include credentials,
unpublished structures, trajectories, or patient/research data in a report.

The workbench treats scientific commands as structured plans and validates
environment receipts and file hashes before execution. It does not accept free
text shell commands, silently install privileged software, or upload project
data. Users remain responsible for reviewing scientific inputs and commands
before running them.
